## Command bar and keyboard shortcuts

The header Search control and Cmd/Ctrl+K open a modal command bar for room
navigation and workspace actions. Search matches all entered terms against action
labels, descriptions and keywords, plus room titles, topics and purposes. Actions
and rooms stay grouped; unavailable actions remain visible with an explanatory
reason. An empty search result offers a reset. Pause/continue is an explicit
command without a single-key shortcut.

Single-key shortcuts: N creates a room; / focuses the topic or message; S toggles
summary; E exports Markdown; J jumps to latest replies; [ opens or toggles rooms;
] opens or toggles setup; U opens weekly usage. ? opens shortcut help, also
reachable from the bar footer. Help includes a persisted switch for single-key
shortcuts. These shortcuts are suppressed while typing or a workspace drawer is
active; repeated and composing keystrokes are ignored, and unrelated modifier
combinations do not trigger actions.
Cmd/Ctrl+K remains available when single-key shortcuts are disabled.
Cmd/Ctrl+Shift+O opens a new room and focuses its topic; Cmd/Ctrl+Shift+S toggles
room navigation; Cmd/Ctrl+/ opens shortcut help. These modifier shortcuts work
while typing and when single-key shortcuts are disabled. Navigation closes any
open command bar or drawer before moving focus. The bar shows platform-specific
modifier hints; N and [ remain available as single-key alternatives.

On the new-room page, Cmd/Ctrl+Enter validates the form, creates the room and
starts its conversation immediately, including from the topic field. It ignores
repeat/composition events and open drawers or command dialogs, and prevents
duplicate submissions. The ordinary Create room action still only creates a room.
If starting fails, the created room remains available with a Start retry action.

The bar extends Jet age with paper heading and footer, white result rows, fine
rules and navy selection, using the existing Manrope/DM Sans pairing. It adds no
shadow or system identity change. Desktop width is capped at (600px); at (640px)
and below it fits within (10px) side margins and the dynamic viewport height.
Results scroll independently, long labels wrap, and compact headers use an
icon-only trigger with an accessible name. Search text remains (16px); dialog
icon buttons and help controls expand to (44px) targets on coarse pointers.

A native modal dialog contains background interaction and keyboard focus. Search
receives focus on opening; dismissal restores the prior target when available.
Arrow keys navigate, Enter runs an available result, and Escape, the close button
or the backdrop dismisses. Combobox/listbox semantics expose selection and
disabled states, and a live status announces the result count. Existing visible
focus outlines remain; reduced motion removes the short arrival translation.
