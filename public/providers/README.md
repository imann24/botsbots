# Provider marks

Monochrome SVG marks from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), distributed under the included MIT license. Brand names and marks belong to their respective owners.

`alibabacloud.svg` represents Alibaba; `amazon.svg` is the AWS mark. All assets are bundled locally and displayed as navy masks inside neutral circular frames by `src/components/model-identity.tsx`.
